# Каталог курсов

Приложение Django для добавления и редактирования курсов через ModelForm.

## Запуск

```bash
cd homeworks/hw3_4
python manage.py migrate
python manage.py runserver
```

Откройте:

- `http://127.0.0.1:8000/courses/` — список курсов
- `http://127.0.0.1:8000/courses/add/` — добавление курса
